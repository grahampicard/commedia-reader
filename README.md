# Commedia Reader

A reader for Dante's *Inferno*, Cantos I–X. Each tercet shows the original text (after the Petrocchi edition) beside a modern Italian paraphrase and an English translation.

- Tap a word in Dante's text for its dictionary form, tense and meaning in that line.
- Tap a line number for notes on word order, idioms and references.
- The verb guide covers the old forms that trip readers up most often.

The paraphrases, translations and notes were written for this reader. The whole site is a single `index.html` with no build step.
